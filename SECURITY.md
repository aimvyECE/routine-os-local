# Security and privacy

This prototype is intended for personal local use. It has no server, account, telemetry or connected AI. Do not treat it as encrypted storage: local browser data and exported JSON are plain text.

Please report a reproducible issue without posting personal notes, exports, credentials or medical information. Use only synthetic data in public reports.

Before publication the repository was checked for credentials, personal content and environment paths. It includes only original source, documentation and fictitious test data. This is a bounded review, not a professional security audit.

Key boundaries: schema-validated imports; text-only rendering of user content; no arbitrary section code; no app network requests; recoverable section archiving; explicit import merge; snapshot checks for stale writes. LocalStorage is not transactional across concurrent tabs. Prefer one editing tab and regular private exports.

Supported version: 0.2 experimental. Visual/browser QA remains incomplete; no production reliability or medical guarantees.
